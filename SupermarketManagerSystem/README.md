# SupermarketManagerSystem

First skeleton version for an ASP.NET Core MVC final project.

## Idea
A supermarket manager system where managers can control products, categories, suppliers, stock movements, employees and store branches.

## Requirement checklist
- ASP.NET Core 8.0 MVC structure
- 4+ controllers
- 1 API controller placeholder
- 4+ entity models
- 10+ views
- Services layer
- Data layer with EF Core-ready DbContext
- Identity-ready ApplicationUser
- NUnit test project
- No migrations included

## Projects
- SupermarketManagerSystem.Web
- SupermarketManagerSystem.Data
- SupermarketManagerSystem.Services
- SupermarketManagerSystem.Tests
